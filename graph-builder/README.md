# Semantic Knowledge Compiler

Semantic Knowledge Compiler (SKC) is an offline compiler for transforming
enterprise metadata into a governed semantic knowledge graph.

The project is currently implemented through Phase 7 of the implementation
plan: metadata extraction, semantic inference, governance review, graph
generation, checkpoints/resume, build reporting, additional connector shells,
and the bundled insurance sample plugin.

Start with [docs/quickstart.md](docs/quickstart.md).
